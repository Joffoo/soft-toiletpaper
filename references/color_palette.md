# 《TOILETPAPER》量化色谱与光学参数词典（以 2026-10-21 分析报告为准）

本文档为 `soft-toiletpaper` 技能的底层数据基石，源自对本地高清图包全域 **3,440 张**（含 **311 张**核心摄影母版）的多模态 K-Means 色彩聚类与物理光影量化测算。数据口径与 `_inbox/TOILETPAPER图片量化分析结论报告.md` 完全一致，冲突时以该报告为准。

> **本文件是色彩与光学数值的唯一出处**：HEX 色值、双色配方、光学实测、材质片段均以此处为准，`SKILL.md` 不复述、不摘要这些数字。任何下游文档（含 `.agents/skills/README.md`）以本文件为校对基准。

## 一、语料基准：纯色底纸只占四成

背景拓扑是全局前提，决定哪些图属于本技能范式：

| 数据集 | 总量 | (A) 高饱和纯色纸 | (B) 无彩色 黑/白/灰 | (C) 实景 / 复杂图纹 | 影棚单色 (A+B) | A / (A+B) |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **核心摄影大片集** | 311 张 | **109 (35.0%)** | 14 (4.5%) | **188 (60.4%)** | 123 (39.5%) | **88.62%** |
| **全域扩展图集** | 3,440 张 | 1,164 (33.8%) | 387 (11.3%) | 1,889 (54.9%) | 1,551 (45.1%) | 75.05% |

- **本技能覆盖的是 (A) 高饱和纯色影棚底这一 35%～40% 子集**。核心大片另有 **60.4%** 是实景与置景环境，那一路不属于本技能的"纯净单色底 + 中央孤立主体"范式。
- **88.62%** 指影棚单色背景内部对彩色纸的偏好率（109/123）：正刊几乎彻底排斥黑白灰底色。
- 构图前提：主体高度集中在画面中央 **60%** 区域，无缝背景纸自然延伸至四边。

## 四、五种对撞配方与三大色彩对抗模式

先说清楚结构，否则配方会被误当成"全是强互补"：

| 模式 | 判据 | 出现率（核心大片） |
| :--- | :--- | :--- |
| **强互补对撞** | $\Delta H \ge 140°$ | **17.7%**（全域 24.9%） |
| **同族暖撞** | $\Delta H \approx 38°$ | 柠檬黄 / 赤橙一类同侧暖色硬撞 |
| **极端明度差** | $\Delta L^* \approx 46$ | 纯黑底 + 高光浅色主体 |

> ⚠️ **全集 $\Delta H$ 中位数为 114°**——低于强互补门槛。把"红蓝互补"当成唯一机制是过度归纳：同族暖撞与明度断崖在法律上同等合法，甚至更常见。
>
> 配方的色值来自单图实测主色簇，与第三节的 K-Means 聚类中心不是同一口径，数值不同属正常。

**为何红蓝交界会"震颤"（Chromostereopsis）**：人眼对 472–652 nm 的纵向色差约 **0.96 D**，在视网膜上形成约 **0.47 mm** 的前后焦点位移；红蓝边界经瞳孔偏心区时产生微小的水平视网膜位移差，被双目立体中枢解码为前后视差。叠加视网膜侧抑制，交界处即出现微弱的发光与浮动感。这是"红蓝对撞"的生理机制，不是修辞。

### 配方 1：泳池冰蓝底 + 番茄红主体（蓝红强互补）

- **背景**：`#01A5DB`（H 194.0°）
- **主体**：`#DA251F`（H 2.0°）
- **色相差**：$\Delta H = 168.0°$
- **光学效应**：视网膜横向色差产生强烈前后深度错动感。

### 配方 2：警戒柠檬黄底 + 赤橙主体（同族暖撞，非互补）

- **背景**：`#FDCF00`（H 50.6°）
- **主体**：`#E4471D`（H 12.3°）
- **色相差**：$\Delta H = 38.3°$，标志性同相暖色硬撞
- **光学效应**：极高反射明黄纸 + 暖红主体形成同相膨胀，配合贴轮廓硬阴影制造警示性张力。

### 配方 3：深红底 + 钴蓝／墨绿主体（双簇对抗）

- **背景**：`#C21C1A`（H 0°，$L^*=41.8$）
- **主体**：`#0F507F` 钴蓝（H 204°，$\Delta H=156°$）／`#157037` 常春藤绿（H 142°，$\Delta H=142°$）
- **光学效应**：深暗红底吸收漫射光，与高冷主体形成深邃戏剧张力。

### 配方 4：墨绿底 + 暖橙主体（复古意式）

- **背景**：`#115848`（H 166.5°）
- **主体**：`#EB6D21`（H 29.8°）
- **色相差**：$\Delta H \approx 136.7°$
- **光学效应**：1970s 意式室内设计复古调性，高纯暖橙在深墨绿上强跳脱。

### 配方 5：纯黑底 + 高光浅肉色主体（极端明度差）

- **背景**：`#020202`（$L^*=0.5$，近乎吸光）
- **主体**：`#B74E20`（H 18°，$L^*=46.5$）
- **明度差**：$\Delta L^* = 46.0$（非 $\Delta H$ 逻辑）
- **光学效应**：剥离背景环境漫反射，断崖明度差强化悬浮感与雕塑感。

## 五、物理光学与硬光参数

> **2026-10 口径**：旧版数字（高光 19.25%、对比度 9.53:1、Sobel 118.87、半影 ≤1.5px、投影 45.0°）经全库复测后作废，以下为现行口径。

| 指标 | 实测值 | 说明 |
| :--- | :--- | :--- |
| **无彩色高亮面积占比**<br>($Y>225 \land C<65 \land \lVert I-I_{bg}\rVert>45$) | 杂志/编辑类 **6.9%**<br>计入白底电商照 **21.0%**<br>白底组自身 72.5% | ⚠️ 该指标**≠ 镜面反射强度**，浅色背景纸本身即可触发（`#DCF0F6` 就满足 $Y=234.7, C=26$），不可用于论证灯具形态 |
| **画面动态对比度 P95/P5** | 中位数 **5.3 : 1**<br>高反差特写 **33.6 : 1** | 旧版把 P90 当作典型值 |
| **阴影边缘过渡宽度**<br>(10%→90% 亮度剖面，625 处) | 中位数 **8.5 px**<br>P10 2.5 px / P90 10.0 px | 硬光成立；"≤1.5 px 零半影"不成立 |
| **阴影过渡区 Sobel 梯度**<br>(亮度 $20 \le I \le 100$，N=120) | 均值 **67.73**<br>中位 63.31 | 边缘陡峭的量化佐证 |

1. **光源形态（推断，非测量）**：硬阴影 + 点状镜面高光 → 符合**小发光面积光源**（裸灯 / 小型闪光）。色温、是否机顶热靴、有无辅灯均无 EXIF 可证，不作断言。
2. **阴影物理**：边缘陡峭、贴身硬切的接触阴影，无大型柔光箱的半影虚化。**投射方向随现场机位灵活多变**，旧版"严格 45.0°"系滤波区间造成的数学假象，已删除；构图不受角度约束。
3. **高光形态**：极小面积针尖状镜面反射斑（Pinpoint Specular Highlights），集中在釉面陶瓷、乳胶、抛光塑料、甘油等光滑介质。
4. **留白与轮廓纯净度**：背景与主体轮廓零色渗，边缘清晰，适合下游抠图与矢量剪影提取。
